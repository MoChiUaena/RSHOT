- 公开内容：统一来源参与资格与可见时间，撤回或纠错后清除失效的派生文字；管理员会话绑定当前认证配置。
- 阅读：多标签页收藏合并，损坏的浏览器记录保留原始内容，异常日期显示兼容；第三方 Markdown 使用 sanitized GFM，图片准备和 GIF 缓存修复。
- 完整站点：图片查看器支持翻图、键盘、焦点和滚动恢复，详情最多展示九项媒体；事件事实和报道共用排序，下载文件使用 RSHOT 名称。

遥感分类、主题、信源、编辑包、提示词、已校准门槛、采集准入、模型请求限额和免费社交读取脚本保持原配置。18 个启用来源不变；停用公众号与未验证的 X 候选不启用，微信读书路线保持停用。发布与 X 采集维持每日北京时间 10:30。读者请求不调用模型。

## 迁移和兼容取舍

新迁移仅追加 `0041`、`0042`、`0043`；已安装 `0039`、`0040` 不变。部署先备份，再停止旧 API、worker 和网页，验证迁移目标后执行增量迁移。`0042` 会将失效来源或证据支撑的历史事件文字退回当前有效出处，并在私有审计中保留修复前内容。模型密钥、社交授权、人工标注、监测记录及备份不属于公开仓库或 Pages 快照。

管理员旧会话升级后需要重新登录一次，认证凭据不变。

三项与上游存在差异的决定：

1. 日期只有年月日时，继续按 RSHOT 的信源时区解释。误判会影响未来信源日期约定，需要重新核对，现有日期不会在此次升级中平移。
2. 新 `0042` 的回退标题采用与运行时代码一致的有效证据规则。代价是维护本项目迁移与上游的差异及其审计、回归检查。
3. 新 `0042` 首次迁移也检查遗留综述的证据归属、mention 和 composite 输入。若范围过宽，可能多清除派生文字；用私有备份、迁移演练、修复前审计及人工记录核对控制这一风险。
